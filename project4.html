Ben & Jerry’s 3D Customizer

Create, customize and order your own ice cream

Overview

For this project, I created an interactive website for the fictional client Ben & Jerry’s. Visitors can customize their own ice cream through a 3D experience and place an order.

The project also includes an admin dashboard where incoming orders can be viewed and managed. This project allowed me to combine design, frontend development, 3D and backend development in one application.

The Concept

The goal was to create a playful experience that fits the colorful identity of Ben & Jerry’s. Users can customize the ice cream by changing [CUSTOMIZATION OPTION 1] and [CUSTOMIZATION OPTION 2]. Once they are happy with their creation, they can enter their information and place the order.

For the visual style, I used [COLORS, FONTS OR VISUAL ELEMENTS]. I wanted the website to feel fun and recognizable while still being clear and easy to use.

Development Process

I built the project from scratch using FRONTEND AND 3D TECHNOLOGIES. The order information is sent to an API made with Node.js and Express. The orders are then stored in a MongoDB database.

One of the biggest challenges was putting my backend online. I solved this by deploying it on a cloud platform and asking for help.

Order Management

I also created a separate admin dashboard with Vue.js. The admin can log in, view all incoming orders and open an order to see the customer name, address and total price.

Each order can be marked as pending, shipped or cancelled. The admin can also delete an order when it is no longer needed.
