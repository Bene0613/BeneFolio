Fictional Weather App

A creative weather experience for imaginary worlds

Overview

This project is a weather app featuring fictional cities from movies, series, and cartoons. It was built to showcase creativity while demonstrating HTML, CSS, and JavaScript skills.

How I Got Started

I brainstormed ideas and chose fictional cities because it allowed for playful weather experiences while practicing interactive UI design.

Bringing it to Life

I built the app using HTML, CSS, and JavaScript, adding animated backgrounds and interactive weather cards for each city. The app is responsive and visually engaging.
